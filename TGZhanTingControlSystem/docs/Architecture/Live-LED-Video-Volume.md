# LED视频实时音量控制

## 产品语义

- 中控讲解执行页提供减小、当前百分比和增大三个控件，每次调整10%，范围为0%至100%。
- 调整对象仅为LED播放端的视频原声，不改变讲解音频音量。
- 调整立即发送到当前活动讲解的LED客户端；没有活动讲解时控件不可用。
- 操作员首次调整后，该音量覆盖当前节点的内容混音配置，并在当前讲解后续节点中保持。
- 当前讲解的音量覆盖值随会话持久化，Server重启恢复会话后继续生效；新讲解仍使用内容配置的默认混音策略。

## 协议与校验

- 控制动作：`PlaybackAction.SetVideoVolume`。
- 请求值：`volume`，0至1的有限小数。
- Server拒绝缺失、非有限值或超出范围的请求，并记录成功操作日志。
- Server向LED下发规范化后的`videoVolume`，LED收到后立即调用现有AVPro播放适配层的音量接口。

## 回归范围

- 服务端测试覆盖合法值下发、非法值拒绝、状态回读、持久化和重启恢复。
- Windows实际播放回归覆盖控制指令到达Player并产生实时音量调整日志。
- Unity工程必须分别完成TouchClient和LedPlayer的Windows构建。
