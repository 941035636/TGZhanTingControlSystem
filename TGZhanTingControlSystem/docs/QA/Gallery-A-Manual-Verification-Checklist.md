> 本清单仅验收 Gallery A。TouchClient 暂时没有“图片展示”入口，LedPlayer 暂时不会响应图集投放，这是后续 Gallery B～D 的范围，不应在本阶段记为缺陷。

## 一、拉取与启动

1. 在公司电脑的项目目录执行：

   ```powershell
   git switch codex/product-upgrade
   git pull --ff-only origin codex/product-upgrade
   git status
   ```

2. 确认 `git status` 没有意外的本地修改。
3. 编译并启动服务端：

   ```powershell
   dotnet build src\Server\TG.Control.Server\TG.Control.Server.csproj -c Release
   dotnet run --project src\Server\TG.Control.Server\TG.Control.Server.csproj -c Release --no-build
   ```

4. 打开管理端，进入“内容中心”。使用该环境已经配置的管理员账号登录。

## 四、版本与回滚

1. 图集按“图片A、图片B、图片C”排序并发布，记下版本号。
2. 调整为“图片C、图片A”，再次发布。
3. 回滚到第一步的版本。
4. 返回内容中心重新打开图集。
