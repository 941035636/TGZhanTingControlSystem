# 开发进度（2026-08-25）

## 工程组成

仓库包含四个可部署工程：

1. `src/TouchClient`：Windows触控终端Unity客户端；
2. `src/LedPlayer`：LED大屏Unity播放客户端；
3. `src/Server/TG.Control.Server`：ASP.NET Core 8 Windows服务端；
4. `src/AdminWeb`：电脑端内容管理后台。

另有两个共享协议库：`src/Shared/TG.Control.Contracts`和
`src/Shared/UnityContracts`，属于上述工程的必要依赖。

## LED播放器处理结果

- 已确认AVPro Video 1.8.9在Unity 2020.3/DX11下产生
  `Unsupported D3D format 0x58`，软解和DirectShow均无法规避；
- LED运行时已切换至LibVLC/UniversalMediaPlayer，并保持原
  `IMediaPlaybackAdapter`业务接口；
- Windows x64原生库和VLC解码模块已包含在工程中，无需现场安装VLC；
- 已修复播放器缺失的日志依赖和移动平台目录扫描异常；
- 最新Unity运行程序集及编辑器程序集编译通过，无新增C#、DLL、入口或D3D格式错误。

## 边界说明

- 原有安卓平板中控继续并存；
- 新系统当前不接入TCP、串口、继电器、红外或WOL设备控制；
- 讲解仅支持人工启动，不提供手机端后台，首期仅支持中文；
- 故障节点允许按策略跳过并继续讲解。

## 换机继续开发

1. 安装.NET 8 SDK、Node.js和Unity `2020.3.35f1c2`；
2. 克隆仓库后进入`TGZhanTingControlSystem`；
3. 执行`scripts\Build-All.ps1`构建服务端和管理端；
4. 分别用Unity打开`src/TouchClient`和`src/LedPlayer`；
5. 不要提交Unity的`Library`、`Temp`、`Logs`、`UserSettings`以及Node的`node_modules`。
