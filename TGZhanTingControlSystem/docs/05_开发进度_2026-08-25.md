# 开发进度（2026-08-25）

## 工程组成

仓库包含四个可部署工程：

1. `src/TouchClient`：Windows触控终端Unity客户端；
2. `src/LedPlayer`：LED大屏Unity播放客户端；
3. `src/Server/TG.Control.Server`：ASP.NET Core 8 Windows服务端；
4. `src/AdminWeb`：电脑端内容管理后台。

另有两个共享协议库：`src/Shared/TG.Control.Contracts`和
`src/Shared/UnityContracts`，属于上述工程的必要依赖。

## LED播放器处理结果

- 已确认AVPro Video 1.8.9在Unity 2020.3/DX11下产生
  `Unsupported D3D format 0x58`，软解和DirectShow均无法规避；
- LED运行时已切换至LibVLC/UniversalMediaPlayer，并保持原
  `IMediaPlaybackAdapter`业务接口；
- Windows x64原生库和VLC解码模块已包含在工程中，无需现场安装VLC；
- 已修复播放器缺失的日志依赖和移动平台目录扫描异常；
- 最新Unity运行程序集及编辑器程序集编译通过，无新增C#、DLL、入口或D3D格式错误。

## 讲解音频迁移与扩展

- 已按现场接线将正式讲解音频从触控终端迁移至连接大屏音响的LED播放主机；
- 服务端单条播放协议可同时下发视频URL、TTS音频URL、混音策略和两路音量；
- LED端在起播前同时完成视频与讲解音频缓存、解码和就绪回报，并在同一Unity帧启动两路媒体；
- 支持“压低视频原声”“保留视频原声”“讲解时静音视频”三种混音策略；
- 暂停、继续、定位、跳过、停止和节点完成判定已统一控制视频与讲解音频；
- 触控端已停止创建正式讲解AudioSource，旧音频播放器代码保留为现场备用能力；
- 管理端讲解节点编辑器已增加混音策略、讲解时视频音量和讲解音量配置。

## LED离线发布与开机同步

- 管理端发布仅写入服务器正式内容版本，不要求LED播放主机在线；
- 新增`/api/content/manifest`内容清单接口，返回当前版本及视频、图片、动画、TTS素材地址；
- LED注册成功后自动获取清单，在后台下载缺失素材，已缓存素材不会重复下载；
- 支持服务器暂时离线、LED关机、下载中断后的自动重连、断点续传和文件大小校验；
- LED开机画面显示素材同步进度，播放仍会在缺失素材时按需补齐；
- 下载响应不支持Range时会自动清理错误追加文件并重新下载，避免大文件损坏；
- 播放缓存和开机同步共用本地内容缓存目录，避免重复下载。

## 多套讲解路线预案

- 讲解路线由服务器持久化保存，中控重启后自动恢复，不再需要每次重新勾选主题；
- 支持多套命名路线，适用于不同客户、接待时长和讲解重点；
- 中控可新建、覆盖保存、分页选择和删除路线，点击预案即可装载对应主题组合；
- 自动记住上次使用的路线，中控下次启动时优先恢复；
- 临时组合讲解继续保留，未保存的选择不会影响已有预案；
- 常用路线改为右侧大卡片展示，显示路线名称和主题数量，并提供“一键讲解”；
- 左侧仅负责当前路线编辑、保存修改和另存，明确显示未保存状态；
- 删除路线增加二次确认，常用路线超过4套时支持翻页；
- 新增`GET/POST /api/routes`和`DELETE /api/routes/{id}`接口，路线数据保存到服务器`Data/narration-routes.json`。

## 边界说明

- 原有安卓平板中控继续并存；
- 新系统当前不接入TCP、串口、继电器、红外或WOL设备控制；
- 讲解仅支持人工启动，不提供手机端后台，首期仅支持中文；
- 故障节点允许按策略跳过并继续讲解。

## 换机继续开发

1. 安装.NET 8 SDK、Node.js和Unity `2020.3.35f1c2`；
2. 克隆仓库后进入`TGZhanTingControlSystem`；
3. 执行`scripts\Build-All.ps1`构建服务端和管理端；
4. 分别用Unity打开`src/TouchClient`和`src/LedPlayer`；
5. 不要提交Unity的`Library`、`Temp`、`Logs`、`UserSettings`以及Node的`node_modules`。
