# 功能覆盖矩阵

| 需求/场景 | 触控端 | 大屏端 | 服务器 | 管理后台 | 设备层 |
|---|---|---|---|---|---|
| 全部板块自动讲解 | 发起、控制、显示进度 | 执行媒体和语音 | 创建路线并统一编排 | 配置默认顺序 | 执行时间线动作 |
| 任意板块组合讲解 | 多选和拖动排序 | 按路线播放 | 校验并生成临时路线 | 管理预设路线 | 按路线执行动作 |
| 板块数量变化 | 动态读取 | 动态读取 | 通用数据模型 | 新增、编辑、排序、停用 | 无需改驱动 |
| 自定义讲解内容 | 展示已发布版本 | 缓存并播放 | 管理版本和引用 | 编辑文案、字幕和媒体 | 配置关联动作 |
| 双屏联动 | 发送请求、显示状态 | 执行权威命令 | 状态机和消息协调 | 查看运行状态 | 提供动作结果 |
| 音画同步 | 不作为主时钟 | 按计划时间播放 | 时间同步和漂移判断 | 配置时间线 | 按计划动作 |
| 无线网络抖动 | 自动重连、受控降级 | 本地缓存、继续当前片段 | 心跳容错和恢复 | 显示离线状态 | 独立维持或重连 |
| 串口继电器 | 显示结果 | 无 | 调用驱动 | 配置参数和通道 | 串口驱动执行 |
| 红外探头 | 显示触发结果 | 响应合法触发 | 规则判断 | 配置触发规则 | 输入、防抖和上报 |
| TCP 设备 | 显示结果 | 无 | 调用驱动 | 配置连接和命令 | TCP 编解码和重连 |
| 内容发布 | 提示版本 | 下载、校验和切换 | 构建发布清单 | 发起发布和回滚 | 可同步配置版本 |
| 故障恢复 | 重连和恢复显示 | 校验会话后续播或复位 | 持久化快照和决策 | 查看及处理故障 | 重连、重试和安全状态 |
| 日志审计 | 上报操作 | 上报播放错误 | 汇总关联 | 查询、筛选和导出 | 记录命令和响应 |
| 开机无人值守 | 自动启动 | 自动启动 | Windows Service 自动启动 | 浏览器访问 | 驱动自动连接 |

## 当前未定但架构已预留

- 真人录音、TTS 或两者并存。
- 音频由大屏端、触控端或独立音响设备输出。
- 多台大屏、多台触控端和主备服务器。
- HTTP、UDP、Modbus、灯光、投影、音响等新增设备协议。
- 领导参观、重点路线、定时讲解和红外自动触发等业务模式。
