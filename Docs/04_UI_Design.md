# UI 功能设计

## 1. 触控客户端页面

### 待机页

- 品牌主题动画或宣传画面。
- 触摸进入。
- 显示网络或系统不可用提示，但不暴露技术错误详情。

### 首页

- 完整讲解入口。
- 自由组合讲解入口。
- 预设路线入口。
- 当前系统状态和维护入口。

### 板块浏览页

- 以卡片或缩略图展示后台发布的全部板块。
- 支持横向滚动、选中状态和板块简介。
- 板块数量动态变化，不依赖固定网格数量。

### 自由组合页

- 多选任意板块。
- 拖动调整顺序。
- 显示预计总时长。
- 清空、全选、恢复默认顺序和开始讲解。

### 讲解控制页

- 当前板块、当前片段、总进度和剩余时间。
- 暂停、继续、上一板块、下一板块、跳转和停止。
- 大屏、服务器和关键设备状态。
- 对不可执行操作给出明确原因，防止重复点击。

### 维护页

- 服务器地址、客户端编号和网络状态。
- 内容版本、缓存状态和更新检查。
- 日志导出、连接测试和受控退出。
- 维护页需要密码或管理员权限。

## 2. 管理后台页面

- 仪表盘：在线客户端、当前讲解、设备状态和故障。
- 板块管理：板块内容、顺序、启停和预览。
- 素材管理：上传、分类、校验、引用关系和替换。
- 时间线编辑：媒体、语音、字幕和设备动作编排。
- 路线管理：完整路线、任意预设组合和预计时长。
- 设备管理：设备参数、命令模板、连接测试和状态。
- 发布管理：内容校验、发布进度、历史版本和回滚。
- 日志中心：运行、操作、通信、设备和故障日志。
- 用户权限：管理员、内容编辑员和操作员。

## 3. 交互原则

- 触控目标尺寸适配 55 英寸屏幕和站立操作距离。
- 核心讲解操作不超过两级页面。
- 所有长操作显示进度，防止用户误以为系统无响应。
- 停止、跳转和设备控制等高影响操作需要防误触设计。
- 无网络、无大屏、素材缺失和设备故障均有独立状态提示。
- UI 风格、动效、字体和色彩后续依据甲方视觉规范确定。
