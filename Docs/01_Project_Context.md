# 多媒体展厅自动讲解系统 - 项目背景

## 项目目标

重新开发一套运行在 Windows 环境中的多媒体展厅自动讲解系统，对接现有展厅控制系统，支持自定义讲解内容、全部板块连续讲解、任意板块组合讲解，并保证大屏画面、语音和设备动作同步联动。

## 运行环境

- 触控终端：Windows 10 64 位，运行 Unity 定制触控客户端。
- 大屏播放端：Windows，运行 Unity 定制大屏客户端。
- 中控服务器：Windows，运行中控服务、内容管理后台和设备协议驱动。
- 主要网络：无线局域网；同时保留千兆有线网络用于调试和应急。

## 触控终端硬件标准

55 英寸 4K 防眩光电容触控屏 + 12 代 i5 处理器 + 16GB 内存 + 512GB SSD + 4GB 以上独立显卡 + Windows 10 64 位 + 千兆有线网络 + Wi-Fi 6 双频无线网卡 + 至少 2 个 USB 3.0，BIOS 支持网络唤醒。

## 当前板块主题

1. 一路向新
2. 历史沿革
3. 不曾忘却的记忆
4. 子分公司
5. 领导关怀
6. 企业荣誉
7. 科技创新
8. 产品体系
9. 数智领航
10. 绿色低碳
11. 敢当石特
12. 党建赋能

板块数量不得在程序中写死。后台必须支持新增、编辑、停用、删除、排序和组合任意数量的板块。

## 已确定能力

- 完整路线自动讲解。
- 任意板块选择、排序和组合讲解。
- 讲解文案、语音、字幕、图片、视频和动画可配置。
- 触控端与大屏端双屏联动。
- 大屏画面、语音和设备控制动作按统一时间线执行。
- 后台支持素材管理、内容发布、设备管控和参数配置。
- 设备协议采用可扩展驱动，首批覆盖串口继电器、红外探头和 TCP 设备。
- 支持运行日志、故障记录、断线重连和异常恢复。

## 尚待甲方补充

- 12 个板块的正式内容、默认顺序、讲解词、媒体文件和时长。
- 触控终端、大屏播放端和服务器的实际设备拓扑。
- 语音从大屏端、触控端还是独立音响系统输出。
- 串口继电器型号、串口参数、通道映射及指令。
- 红外探头型号、接入方式、触发规则和防抖要求。
- TCP 设备清单、地址、端口、协议和控制命令。
- 音画同步允许误差及故障恢复验收标准。
